# Math formulars
>The project helps the user work more quickly with mathematical formulas for calculating the properties of geometric shapes.

## Circle.py:
>The file contains functions that perform calculations related to a circle.
### Function's descriprion:
* **def area(r)** - function takes the circle's radius and returns its area.
<br>
> **Execution example**:
<br>
>> input: 2
<br>
output: 12.566370614359172
<br>
<br>
>> input: 10
<br>
output: 314.1592653589793
<br>
<br>
>> input: 0
<br>
output: 0.0

* **def perimeter(r)** - function takes the circle's radius and returns its perimeter.
<br>
> **Execution example**:
<br>
>> input: 2
<br>
output: 12.566370614359172
<br>
<br>
>> input: 10
<br>
output: 62.83185307179586
<br>
<br>
>> input: 0
<br>
output: 0.0
